# TubeLayout

YouTube の再生ページの配置を、設定画面で好みに合わせて変える Chrome 拡張機能です。

- **以前のレイアウトに戻す**：YouTube が試験的に出している新しい再生ページ（関連動画がプレイヤーの下に並び、右の列にタイトル・概要欄・コメントが入る形）を使わず、以前のレイアウト（右に関連動画）で表示します。既定で ON です。ウィンドウが狭くても右に関連動画を出せるよう、2 列にする最小の幅も 1000px から 800px に下げています
- **右端のアイコン列**：概要・コメントなどを開くボタンの列を、関連動画の上に横一列で並べる・隠す
- **プレイヤー**：横幅いっぱいに広げる（左右の余白をなくす）、高さ・幅の上限、動画の縦横比によらず高さをそろえる、角の丸めをやめる、周りの光（アンビエント モード）を消す
- **関連動画**：右・左・表示しないの切り替え、横の列の幅、サムネイルの幅、タイトルの文字の大きさ、絞り込みボタンやショート動画を隠す
- **コメント・概要欄**：コメントを横の列（関連動画の上）に置く・隠す、概要欄を最初から開く
- **タイトル・ボタン**：タイトルの文字の大きさ、共有・保存などのボタンの文字やボタンの列を隠す、チケット・グッズの棚を隠す

設定画面には、設定に合わせて動く再生ページの見取り図があります。設定はすぐに保存され、開いている YouTube のタブにもその場で反映されます。ツールバーのアイコンを押すと設定画面が開きます。

## 入手・導入

Chrome ウェブストアには出していません。紹介ページから zip をダウンロードし、デベロッパー モードの「パッケージ化されていない拡張機能を読み込む」で導入します。手順・更新方法・更新履歴は紹介ページにあります。

**https://vel.works/chrome_ext/tubelayout/**

このリポジトリをそのまま読み込んでも動きます（リポジトリ直下が拡張のフォルダです）。

## 権限と通信

- 権限は設定の保存（`storage`）だけです。content script は `https://www.youtube.com/*` でだけ読み込まれます
- 拡張機能からの通信はありません。設定は Chrome の同期ストレージに保存します

## 開発

ビルドはありません（Manifest V3・素の JavaScript）。

| パス | 内容 |
|---|---|
| `settings.js` | 設定のデフォルト値（content script と設定画面の両方が読み込む） |
| `page.js` | ページ側（MAIN world）で動く。YouTube の実験フラグを書き換え、以前のレイアウトで表示させる |
| `content.js` | content script。設定から CSS を組み立てて当て、コメントの移動と概要欄の展開を行う |
| `background.js` | ツールバーのアイコンで設定画面を開く |
| `options.*` | 設定画面 |
| `test/` | 実際の YouTube で配置を記録する検証スクリプト（Python + Playwright）。[test/README.md](test/README.md) |
| `scripts/release.py` | 配布用 zip を作る |

manifest の `key`（公開鍵）で拡張 ID を固定しています。新しい版を別のフォルダに展開しても、設定が引き継がれます。

## デザイン

設定画面の見た目は、[デジタル庁デザインシステム](https://design.digital.go.jp/dads/)の基礎（カラー・タイポグラフィ・余白・角の形状・フォーカス表示）をもとにしています。色の値は公式の [design-tokens](https://github.com/digital-go-jp/design-tokens)（MIT）によります。デジタル庁が作成・公認したものではありません。
